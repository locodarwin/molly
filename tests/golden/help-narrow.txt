            Molly - Keyboard Reference

FILES
  Ctrl-S         Save file
  Ctrl-O         Open a file
  Ctrl-Q         Quit
  Ctrl-?         This help screen

MOVEMENT
  Arrows         Move cursor
  PgUp/PgDn      Page up / down
  Home/End       Line start / end
  Ctrl-G         Go to line

SELECTION
  Shift+Arrows   Extend selection
  Shift+Home/End To line edge
  Shift+PgUp/Dn  Extend by page

EDITING
     In prompts: Enter accepts   Esc cancels
     PgUp/PgDn scroll   any other key returns
